# Thiết kế trang đăng ký với Bootstrap Forms

Trang đăng ký responsive dùng Bootstrap 5.3.3 và CSS tùy chỉnh:

- Họ tên, email, mật khẩu, xác nhận mật khẩu.
- Giới tính dạng radio, sở thích dạng checkbox và quốc gia dạng select.
- Bootstrap form controls, form validation feedback và nút `btn-primary`.
- JavaScript kiểm tra trường bắt buộc, email, độ dài mật khẩu và xác nhận mật khẩu.

Đây là giao diện demo phía trình duyệt: form không gửi, lưu trữ hoặc tạo tài khoản thật. Khi dữ liệu hợp lệ, trang chỉ hiển thị thông báo xác nhận minh họa. Mở `index.html` khi có kết nối mạng để tải Bootstrap từ CDN.
