SCSS · npm · Sass CLI

Viết SCSS rõ ràng. Biên dịch CSS thật nhanh.

Tổ chức style với biến, lồng selector và partials. Dùng Sass CLI để tạo CSS sẵn sàng cho trình duyệt.

Xem quy trình
scss/main.scss
@use "sass:color";

$brand: #496fe0;

.button {
  color: white;
  background: $brand;

  &:hover {
    background: color.adjust($brand, $lightness: -10%);
  }
}

Một công cụ, nhiều tiện ích

SCSS giúp stylesheet dễ phát triển hơn

Sass bổ sung các tiện ích cho CSS và biên dịch thành CSS tiêu chuẩn mà trình duyệt có thể đọc.

01

Biến và giá trị dùng chung

Lưu màu sắc, khoảng cách và các giá trị thiết kế tại một nơi.

02

Nesting và partials

Nhóm quy tắc có liên quan, chia style thành các file dễ quản lý.

03

CLI và watch mode

Tự động biên dịch một file hoặc cả thư mục khi có thay đổi.

Quy trình cơ bản

SCSS đầu vào → CSS đầu ra

Chạy lệnh build để biên dịch, hoặc bật watch để Sass tự cập nhật CSS khi bạn lưu SCSS.

Lệnh trong dự án này

npm install cài Sass cục bộ, npm run build biên dịch nhiều file và npm run watch theo dõi thay đổi.
