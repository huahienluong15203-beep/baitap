# Bootstrap Grid System — Fieldnotes

Trang mẫu để thực hành Bootstrap Container, Grid System và Navbar có dropdown.

## Bố cục responsive

- Dùng `.container` để giới hạn chiều rộng trang.
- Khu vực bài viết dùng `.row` với `.col-12 col-lg-8`.
- Sidebar dùng `.col-12 col-lg-4`: ở màn hình nhỏ hơn 992px nằm dưới bài viết; từ 992px trở lên hiển thị bên cạnh theo tỷ lệ 8/4.
- Navbar dùng các component Bootstrap 5: responsive collapse và dropdown.
- Bootstrap Bundle cung cấp JavaScript cho menu thu gọn và dropdown.

Mở `index.html` bằng trình duyệt có kết nối mạng để tải Bootstrap 5.3.3 từ CDN.
