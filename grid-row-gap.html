CSS Grid: grid-row-gap

Thuộc tính grid-row-gap đặt khoảng cách giữa các hàng của Grid. Thuộc tính hiện đại tương đương là row-gap.

Ví dụ 1: Khoảng cách cố định

Dùng giá trị 20px để tạo khoảng cách cố định giữa hai hàng. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  grid-row-gap: 20px;
}

Ví dụ 2: Khoảng cách phần trăm

Với chiều cao lưới 400px, giá trị 5% tạo khoảng cách hàng bằng 5% chiều cao đó. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  grid-row-gap: 5%;
  height: 400px;
}
