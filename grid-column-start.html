CSS Grid: grid-column-start

Thuộc tính grid-column-start xác định đường kẻ cột nơi một Grid Item bắt đầu. Ô màu vàng là Item 1 trong mỗi ví dụ.

Ví dụ 1: Giá trị auto

auto không chỉ định đường bắt đầu; Grid tự đặt Item 1 theo luồng sắp xếp thông thường. 

.grid-container {
  display: grid;
  grid-template-columns: 100px 100px 100px;
  gap: 10px;
}
.item1 {
  grid-column-start: auto;
}

Ví dụ 2: Giá trị span 2

Item 1 chiếm hai cột. Grid tự tìm vị trí bắt đầu phù hợp để đặt item theo thứ tự. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}
.item1 {
  grid-column-start: span 2;
}

Ví dụ 3: Chỉ định đường kẻ cột

Lưới có 4 cột nên có 5 đường kẻ. Đường kẻ số 2 nằm ngay trước cột thứ hai. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}
.item1 {
  grid-column-start: 2;
}

Đường kẻ: 1 | 2 | 3 | 4 | 5
