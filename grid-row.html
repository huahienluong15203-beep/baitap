CSS Grid: grid-row

Mỗi lưới có 3 cột, 3 hàng và 6 ô. Ô màu vàng là Ô 1; so sánh vị trí và chiều cao của ô này ở ba cách khai báo.

Ví dụ 1: Hàng 1 đến đường 3

Ô 1 bắt đầu ở hàng đầu và chiếm hai hàng.

.grid-container {
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 100px);
  gap: 10px;
}
.item1 {
  grid-row: 1 / 3;
}

Ví dụ 3: Giá trị span 2

Grid tự chọn vị trí; Ô 1 kéo dài qua hai hàng. 

.grid-container {
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 100px);
  gap: 10px;
}
.item1 {
  grid-row: span 2;
}
