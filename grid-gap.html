CSS Grid: grid-gap

grid-gap là shorthand đặt khoảng cách hàng trước, khoảng cách cột sau. Ô màu trong mỗi ví dụ được sắp xếp bằng CSS Grid.

Ví dụ 1: Khoảng cách bằng nhau

Một giá trị 20px áp dụng cho cả khoảng cách hàng và cột. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  grid-gap: 20px;
}

/* Tương đương */
grid-row-gap: 20px;
grid-column-gap: 20px;

Ví dụ 2: Khoảng cách khác nhau

Giá trị thứ nhất 30px dành cho hàng; giá trị thứ hai 10px dành cho cột. 

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-gap: 30px 10px;
}

/* Tương đương */
grid-row-gap: 30px;
grid-column-gap: 10px;

CSS hiện đại cũng cho phép viết gap: 30px 10px. Thuộc tính gap dùng được với Grid và Flexbox.
